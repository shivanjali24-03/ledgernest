# Security policy

LedgerNest handles financial data, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private
[**Report a vulnerability**](https://github.com/shivanjali24-03/ledgernest/security/advisories/new) form instead.
Include the steps to reproduce, the impact, and any suggested fix. You'll get a reply within 7 days.

## Supported versions

Only the latest release on `main` receives security fixes while the project is in early development.
